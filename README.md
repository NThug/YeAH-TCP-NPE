# YeAH-TCP — NS-3.44 Network Performance Evaluation

This repository contains the C++ NS-3 simulation, launch scripts, analysis scripts, validated summary tables, figures and (in the full archive) 32 raw experiment datasets. It accompanies the **separately submitted PDF report**.

## Provenance

- Simulator: NS-3.44, upstream Git commit `43dce6710b8df69685e3479c1d33a571dda714ea`.
- Congestion-control algorithm: **upstream `TcpYeah` in NS-3.44**, not a newly written or patched TCP algorithm.
- Experiment driver: `simulation/yeah-experiment.cc`, SHA-256 `460600eea2ba2341df49a284022ebd678d1d32adad5b695b8de93c97c1ff5969`.
- Optimized build in the original experimental environment; all 32 experimental scenarios used the same driver and simulator revision.
- 32 runs (H1–H4), each with simulation duration 600 s. Only **one run per configuration**; no confidence intervals can be inferred.
- Results and analysis refer to NS-3 simulations, **not an exact reproduction** of the original authors' physical Linux testbed. SURGE background traffic and Limited Slow Start were not implemented.

## Layout

- `simulation/yeah-experiment.cc`: C++ simulation program.
- `scripts/run_H1.py` ... `run_H4.py`: original experiment orchestration, with source and executable identity guards tailored to the original WSL environment.
- `scripts/analyze_H1.py` ... `analyze_H4.py`: independent analysis and figure generation from raw CSV.
- `scripts/audit_I1.py`, `scripts/compare_I2.py`: recomputation, hash checks and paper comparison.
- `refs/paper_table_I_2007.csv`: published numeric values used in Table I comparisons.
- `results/raw/experiments/h1` ... `h4`: per-run original CSV, config, logs and status **only in FULL_REPRO archive** (the light archive omits `timeseries.csv`).
- `results/summary/`: derived tables; `results/figures/`: plots generated by Python.
- `docs/`: audit notes and provenance; `tests/`: unit-test log.

## Requirements

Ubuntu/WSL, Python 3, g++, CMake, Ninja, and **NS-3.44**. Analysis scripts require `matplotlib` and (for report generation) `python-docx`. They were validated in the original project folder `~/projects/YeAH-TCP-NPE`. The original runner scripts use absolute paths and binary SHA checks; on another computer, adapt those guards to the local environment rather than misrepresenting a different binary as the original one.

## Rebuild the simulation

Clone and build NS-3.44 following the ns-3 documentation, then copy `simulation/yeah-experiment.cc` into `<ns-3.44>/scratch/yeah-experiment.cc`.

One representative T1 run (YeAH, RTT 60 ms, 500 Mbps, 600 s, 100% BDP) uses these arguments in NS-3's build tree:

```bash
./ns3 run 'scratch/yeah-experiment --tcp1=yeah --tcp2=yeah --flows=2 --capacity=500 --rtt1=60 --rtt2=60 --bufferRatio=1 --duration=600 --loss=0 --flow2Start=0 --flow2Stop=600 --seed=1 --run=1 --mss=1448 --initialCwnd=10 --initialSsthreshSegments=0 --out=/tmp/yeah-rtt60'
```

For the **exact original commands** and other scenario parameters, consult `results/raw/experiments/<batch>/<scenario>/status.json` and `config.json` in the full archive. These are the original command records, not recreated guesses. Rebuilt executables can produce different binary hashes across compilers and environments; the study's reported data use the recorded original binary.

## Verify and regenerate tables and figures

Extract **FULL_REPRO** into `~/projects/YeAH-TCP-NPE` (or adapt source paths in relevant scripts), then:

```bash
python3 scripts/analyze_H1.py
python3 scripts/analyze_H2.py
python3 scripts/analyze_H3.py
python3 scripts/analyze_H4.py
python3 scripts/audit_I1.py
python3 scripts/compare_I2.py
```

The original tests produced 8/8 pass in each group (32/32), 20 PNG and 20 SVG figures, and derived tables. `scripts/audit_I1.py` independently checks each raw CSV and source hash. The report must use these validated data and reflect the different source model/measurement windows documented in the paper-comparison notes.

## Limitations and submission contents

- `YeAH_TCP_CODE_RESULTS.zip` is a lightweight source/results archive. It intentionally excludes large raw `timeseries.csv` files, so it **cannot perform a full raw-data audit on its own**.
- `YeAH_TCP_FULL_REPRO.zip` includes raw `timeseries.csv` for all 32 runs, allowing the analysis and audit to be reproduced.
- The formatted PDF report is a separate file; replace cover placeholders and update the Word table of contents before PDF export.
- The raw datasets have not been modified to match results from the original paper. Differences are reported, not hidden.
